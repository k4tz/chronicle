## Task
Create a rich, detailed world foundation that includes:

1. **Cosmology** - Universe structure, creation myths, planes of existence
2. **History** - Major eras, events, civilizations, turning points
3. **Geography** - Continents, regions, climate, notable features
4. **Political Landscape** - Nations, power structures, conflicts
5. **Economy** - Trade, resources, currency, industries
6. **Culture** - Social norms, traditions, art, religion, daily life
7. **Magic/Tech Rules** - System rules, limitations, costs

## Guidelines
- Create interconnected elements that support storytelling
- Include hooks for character development and plot
- Balance detail with flexibility for the author to build upon
- Ensure internal consistency
